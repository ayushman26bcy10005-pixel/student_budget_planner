# Student Budget Planner

This is a terminal-based Python application built to help students manage their money, track expenses, and stay on top of a monthly budget. It runs entirely through the command line with text inputs.

## How to get it running

1. Open your terminal or command prompt.
2. Make sure you are inside the folder where `main.py` is saved.
3. Start the application by typing this command and hitting enter:

```bash
python main.py
```

## How it works
Once you run the script, it will guide you through text prompts right inside your terminal. You can input income streams, list recurring college expenses, and view your remaining balance directly in the command window without needing a browser or extra setup.
